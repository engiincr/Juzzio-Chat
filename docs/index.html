Sık sorulan sorular

Juzzio nedir?

Juzzio, farklı dilleri konuşan insanların canlı çeviriyle sesli/görüntülü konuşup şifreli mesajlaşabildiği bir Android uygulamasıdır.

Juzzio ücretsiz mi?

Evet, Juzzio şu anda ücretsiz BETA olarak GitHub üzerinden APK ile dağıtılmaktadır.

Juzzio kaç dili destekliyor?

Uygulama arayüzü ve çeviriler 220’den fazla dili destekler.

Mesajlarım güvende mi?

Birebir sohbetler uçtan uca şifrelidir; sunucu mesaj içeriğini okuyamaz.
