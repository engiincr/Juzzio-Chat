FAQ

What is Juzzio?

Juzzio is an Android app for live-translated voice/video calls and encrypted messaging between people who speak different languages.

Is Juzzio free?

Yes. Juzzio is currently a free BETA distributed as an APK on GitHub.

How many languages does Juzzio support?

The interface and translations support more than 220 languages.

Are my messages private?

One-to-one chats are end-to-end encrypted; the server cannot read message content.
